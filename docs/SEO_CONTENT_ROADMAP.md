# SEO content roadmap

## P0 — implemented foundations

- Canonicals, unique route metadata, social metadata, robots, sitemap, status handling
- Structured-data utilities and philosopher entity graphs
- Crawlable philosopher directory and deterministic internal links
- Custom 404, error/loading states, manifest, and automated SEO guard

## P1 — implemented existing-page improvements

- Philosopher name as the primary H1 and visible direct summary
- Breadcrumb UI and matching schema
- Source-policy, methodology, editorial-policy, and academic-reference signals
- Responsive WebP entity images with descriptive alt text

## P1 — human editorial review required

- Verify every quotation against a named edition and translator
- Review disputed biographies and philosophical classifications
- Confirm copyright status for portraits and modern translations
- Add genuine maintainer identity only when the maintainer chooses to publish it

## P2 — recommended content, not auto-generated

- Substantial concept hubs: rationalism, empiricism, absurdism, epistemology
- Comparisons: Plato vs Aristotle, rationalism vs empiricism, Hume vs Kant
- Major-work guides with edition-aware citations
- A curated philosophy glossary

Create these only when each page has original standalone value and reviewed sources.

## P3 — advanced operations

- Human-reviewed Hindi routes and reciprocal hreflang
- Secure IndexNow integration tied to meaningful publishing events
- Search Console and Bing monitoring dashboards
- Rendered-HTML crawler tests in CI
- Real-user Core Web Vitals monitoring
