# SEO architecture

## Canonical policy

`https://western-philosophy.vercel.app` is the production origin. Existing philosopher URLs remain canonical at `/course/[slug]`; no URL migration or redirect chain was introduced. Query parameters do not create alternate canonicals.

## Metadata

Global defaults live in `app/layout.tsx`. Reusable page metadata is generated by `lib/seo/metadata.ts`. Every indexable static page has a canonical, description, robots directive, Open Graph fields, and Twitter card. Each philosopher receives entity-specific metadata from the shared course data.

## Structured data

`lib/seo/schema.ts` builds escaped JSON-LD rendered by `components/seo/JsonLd.tsx`. The site uses `WebSite`, `Organization`, `WebPage`, `CollectionPage`, `ItemList`, `Person`, `Course`, and `BreadcrumbList` only where the visible page supports them. No review, rating, QAPage, or fabricated author schema is emitted.

## Crawl and index controls

- `app/sitemap.ts` lists canonical public pages and philosopher images.
- `app/robots.ts` allows public content and excludes private account, API, and auth routes.
- Missing philosopher slugs call `notFound()` and dynamic unknown slugs are disabled.
- `/account`, `/api`, and `/auth` are not intended for indexing.
- `/llms.txt` is supplementary documentation, not a ranking mechanism.

## International SEO

English is the current canonical indexed language. The interface translator does not create stable translated URLs, so hreflang is intentionally omitted. Add `/hi/...` routes, self-canonicals, reciprocal `en`/`hi` hreflang, and human-reviewed content before indexing Hindi pages.

## Content and citation policy

Philosopher pages expose the entity name above the fold, a direct summary, core concepts, primary works, quotation context, and an academic reference. Editorial, methodology, and source-policy pages document correction and evidence standards. Edition-level review of every quotation remains a human editorial task.

## Publishing checklist

- [ ] Search intent and entity are defined.
- [ ] Title and description are unique and natural.
- [ ] Exactly one descriptive H1 exists.
- [ ] H2/H3 hierarchy reflects visible content.
- [ ] Canonical points to the preferred URL.
- [ ] Images have useful alt text and explicit sizing.
- [ ] Sources distinguish primary texts from scholarship.
- [ ] Internal links use descriptive anchors.
- [ ] Breadcrumb UI and schema agree.
- [ ] Structured data matches visible content.
- [ ] Page is included in the sitemap if indexable.
- [ ] Mobile layout and keyboard access are checked.
- [ ] `npm run seo:audit`, `npm run typecheck`, and `npm run build` pass.

## Search Console setup

1. Add and verify the production URL-prefix or domain property.
2. Submit `https://western-philosophy.vercel.app/sitemap.xml`.
3. Inspect the homepage, philosopher hub, and representative course URLs.
4. Monitor Page Indexing, Core Web Vitals, HTTPS, and enhancement reports.
5. Request re-indexing only after substantive changes.

## Bing setup

1. Verify the site in Bing Webmaster Tools.
2. Submit the same sitemap.
3. Review crawl and URL inspection reports.
4. Add IndexNow only when a secure key and a real publishing workflow exist.

## Performance budget

Target LCP below 2.5 seconds, INP below 200 ms, and CLS below 0.1 at the 75th percentile. Keep philosopher prose in server-rendered HTML, use responsive WebP images, limit third-party scripts, and avoid sacrificing usability for a synthetic score.
